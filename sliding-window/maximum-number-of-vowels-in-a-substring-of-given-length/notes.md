# Maximum Number of Vowels in a Substring of Given Length

## Решение

### Скользящее окно фиксированной длины — O(n), O(1)

Сначала считаем количество гласных в первых `k` символах строки и сохраняем его в `vowSum`. Начальный максимум `res` равен этому значению.

Затем сдвигаем окно на один символ: если уходящий символ `s[l-1]` — гласная, уменьшаем `vowSum`; если входящий `s[r]` — гласная, увеличиваем. После сдвига обновляем максимум. Гласные проверяем через множество `map[byte]struct{}` из пяти символов: `a`, `e`, `i`, `o`, `u`.

Если максимум достиг `k`, возвращаем ответ досрочно: в окне длины `k` не может быть больше `k` гласных.

## Почему это работает

`vowSum` всегда хранит число гласных в текущем окне. При сдвиге меняются только два символа: один выходит из окна, другой входит. Их учёт сохраняет правильный счётчик без повторного обхода всего окна.

Первое окно учитывается при инициализации `res`, а цикл последовательно рассматривает все остальные окна, включая последнее. Поэтому `res` хранит максимум среди просмотренных подстрок длины `k`.

## Что важно запомнить

- Длина окна фиксирована: при каждом сдвиге одновременно убираем один символ и добавляем один новый.
- `vowSum` — счётчик текущего окна, `res` — лучший результат за весь обход. Это разные величины.
- При начале цикла `l = 1`, `r = k`: выходит символ с индексом `0`, входит символ с индексом `k`. После обновления окно занимает индексы от `l` до `r` включительно.
- Условие `r < len(s)` позволяет обработать последнее окно и не выйти за границы строки.
- Индексация по байтам подходит для условия задачи: строка состоит из строчных английских букв.
- Время — `O(n)`, где `n = len(s)`: первое окно и оставшиеся символы обрабатываются линейно. Дополнительная память — `O(1)`, поскольку множество содержит ровно пять гласных.

## Замечания к первому варианту и исправления

- В первом цикле одновременно увеличивались `res` и `vowSum`. Теперь считается только `vowSum`, а начальный максимум задаётся после цикла — повторное обновление двух переменных убрано.
- Добавлен досрочный возврат при `res == k`. В текущем варианте проверка выполняется после сдвига окна. Если уже первое окно полностью состоит из гласных, ответ всё равно корректен, но при наличии следующего окна произойдёт один лишний сдвиг.

## Оценка

Логических ошибок не обнаружено. Решение корректно при ограничениях задачи `1 <= k <= len(s)` и имеет оптимальную сложность в худшем случае.

Краевые случаи: при `k == len(s)` цикл сдвига не выполняется; при отсутствии гласных ответ равен `0`; при окне только из гласных ответ равен `k`. Для текущего примера `s = "weallloveyou"`, `k = 7` ответ — `4`.
