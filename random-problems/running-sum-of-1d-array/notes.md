# Running Sum of 1d Array

## Решение

### Префиксные суммы с отдельным результатом — O(n), O(n)

Один проход по массиву. Переменная `sum` хранит накопленную сумму: на каждом шаге добавляем текущий элемент и записываем сумму в `run[i]`. Результирующий слайс заранее создаётся длиной `len(nums)`, исходный массив не изменяется.

## Что важно запомнить

- После обработки индекса `i` переменная `sum` равна сумме элементов `nums[0]` … `nums[i]`. Это и есть значение префиксной суммы для текущей позиции.
- Сначала добавляем текущий элемент, затем записываем результат — текущий элемент входит в сумму.
- `make([]int, len(nums))` создаёт слайс нужной длины, поэтому можно сразу записывать по индексу, без `append`.
- Время — `O(n)`: каждый элемент обрабатывается один раз. Память под результат — `O(n)`, дополнительная память без учёта результата — `O(1)`.
- Отрицательные числа и нули не требуют отдельной обработки. Для пустого входа возвращается пустой слайс.

## Оценка

Решение корректное и простое. Время оптимально: для вычисления всех префиксных сумм нужно прочитать каждый элемент. Логических ошибок при разборе не обнаружено; трудности при решении не обсуждались.

## Альтернатива

Если допустимо изменять исходный массив, префиксные суммы можно хранить прямо в нём. Это позволяет обойтись без отдельного слайса результата и использовать `O(1)` дополнительной памяти. Текущий вариант сохраняет входные данные.
