# Max Number of K-Sum Pairs

## Решение

### Частотная хеш-таблица — O(n) по времени, O(u) по памяти

Здесь `n = len(nums)`, `u` — количество различных значений. Сначала считаем частоты всех чисел в `count`. Затем снова проходим по массиву: если у текущего числа есть доступный экземпляр, временно уменьшаем его счётчик и проверяем дополнение `k - n`.

Если дополнение доступно, расходуем один его экземпляр и увеличиваем число операций. Если нет — восстанавливаем счётчик текущего числа. Значения с нулевой частотой пропускаем: все их экземпляры уже использованы в парах.

## Почему это работает

У каждого значения есть единственное подходящее дополнение до `k`, поэтому создание пары сразу не мешает другим вариантам. Для двух различных значений можно составить столько пар, сколько экземпляров есть у менее частого из них. Если оба значения равны, каждая пара расходует два экземпляра одного числа.

`count` хранит количество ещё не использованных экземпляров. Уменьшение обоих счётчиков после создания пары гарантирует, что один элемент не будет использован повторно. Повторный обход исходного массива даёт достаточно попыток для формирования всех доступных пар.

## Что важно запомнить

- Нужны частоты, а не просто множество: одинаковые числа могут участвовать в нескольких разных парах.
- Сначала расходуем текущий экземпляр и только потом проверяем дополнение. При `n == k - n` это не позволяет составить пару из одного элемента.
- Если дополнение не найдено, восстанавливаем частоту текущего числа: неудачная попытка не должна расходовать элемент.
- В Go чтение отсутствующего ключа из `map[int]int` возвращает `0`, поэтому отдельная проверка наличия ключа здесь не нужна.
- Обход идёт по исходному массиву, но доступность элементов определяется счётчиками, а не индексами.
- Ожидаемое время — `O(n)`: два линейных прохода с операциями хеш-таблицы. Дополнительная память — `O(u)`, в худшем случае `O(n)`.

## Оценка

Логических ошибок при разборе не обнаружено. Решение правильно обрабатывает дубликаты, отсутствие подходящих пар и пары из одинаковых значений. Для текущего примера при `k = 2` четыре единицы дают две пары, поэтому ответ — `2`.

Краевые случаи: один экземпляр числа `k / 2` не образует пару; нечётное количество таких чисел оставляет один неиспользованный экземпляр; пустой массив возвращает `0`.
